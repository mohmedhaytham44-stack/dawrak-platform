# دورك — النسخة التجريبية الموسعة

## ما يظهر في النسخة
- واجهة العميل وحجز الدور واستعراض المحلات والخدمات والعروض.
- لوحة صاحب المحل لإدارة الحالة والطابور والصور والعروض وملاحظات العملاء.
- لوحة المؤسس لإدارة أنواع الأنشطة والمحلات والتوثيق والإيقاف، ومؤشرات الاستخدام، وباقات الاشتراك، والحملات، وهوية المنصة، وسجل العمليات.
- الأدوار المعتمدة فقط: المؤسس، صاحب المحل، العميل. لا يوجد دور مشرف.
- الوضع الفاتح والداكن للعميل وصاحب المحل/المؤسس كلٌ بتفضيله المحلي.
- نطاق التجربة: حلوان، حلاقة رجالي وصالونات تجميل افتراضيًا، مع إمكانية إضافة تصنيفات مستقبلًا من لوحة المؤسس.

## التشغيل
افتح `demo/dawrak-final-demo.html` في متصفح حديث.

## تنبيه مهم
هذه واجهة تجريبية محلية: البيانات والإعدادات محفوظة في LocalStorage على نفس الجهاز والمتصفح. ليست نظامًا متعدد المستخدمين، ولا يوجد تسجيل دخول آمن أو صلاحيات خادم أو دفع إلكتروني أو إشعارات فعلية أو نشر عام. أزرار الأمان والتحقق بخطوتين توضيحية لحين ربط Backend/Auth حقيقي. لا تستخدمها لاستقبال حجوزات حقيقية. ملف `supabase/schema.sql` مسودة تأسيسية تحتاج مراجعة واختبارًا وربطًا بالواجهة قبل الإنتاج.
